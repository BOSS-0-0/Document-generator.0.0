ИНСТРУКЦИЯ ПОЛЬЗОВАТЕЛЯ: ГЕНЕРАТОР ДОКУМЕНТАЦИИ 0-М

НАЗНАЧЕНИЕ ПРОГРАММЫ
Программа предназначена для быстрого и автоматизированного заполнения санаторно-курортных карт (форма 072-М) и других документов на основе шаблонов Microsoft Word. Она позволяет создать набор полей, массово загрузить в них данные и мгновенно получить готовый документ Word или таблицу Excel.

ЗАПУСК ПРОГРАММЫ
Так как вы используете автономную версию (EXE-файл), установка Python или дополнительных библиотек не требуется.
Для начала работы просто запустите исполняемый файл программы двойным щелчком мыши.
Требования к системе:
Операционная система Windows.
Установленный Microsoft Word (желательно) или LibreOffice для просмотра и редактирования итоговых документов.

ОСНОВНОЙ РАБОЧИЙ ПРОЦЕСС (ПОШАГОВО)
Шаг 1. Загрузка шаблона
В верхнем меню программы выберите "Файл", затем "Открыть шаблон".
Выберите ваш файл шаблона Word.
Важно: В самом документе Word места для заполнения должны быть помечены ключами в фигурных скобках, например: {UfCrm1702382207} или {ФИО}. Программа найдет эти ключи и заменит их на введенные данные.
Шаг 2. Создание полей
В левой части окна нажмите кнопку "Поля 072-М". Программа автоматически создаст стандартный набор полей (ФИО, Полис, СНИЛС, Диагноз и т.д.) с правильными ключами из вашего шаблона.
Если нужно добавить свое уникальное поле, заполните форму "Поле" в левой части экрана (введите название, выберите тип, укажите ключ) и нажмите "Сохранить поле".
Шаг 3. Заполнение данных
Существует два способа заполнения данных:
Способ А: Ручной ввод
Выберите нужное поле в списке слева.
В форме справа введите значение (для даты используйте отдельные окошки дня, месяца и года).
Нажмите "Сохранить поле".
Способ Б: Массовая вставка (Рекомендуемый способ)
Скопируйте текст с данными пациента из вашей CRM-системы, почты или другого источника.
В программе нажмите кнопку "Вставить данные".
В открывшемся окне текст уже будет автоматически вставлен из буфера обмена.
Нажмите кнопку "Вставить в документ". Программа сама распознает строки, обновит поля и сразу откроет готовый документ.
Шаг 4. Экспорт результата
Убедитесь, что в правой части экрана установлена галочка "Использовать исходный Word-шаблон, если он загружен" (это сохранит красивое форматирование, шрифты и таблицы вашего исходного файла).
Нажмите "Скачать Word" для получения готового документа или "Скачать Excel" для выгрузки данных в таблицу.
После успешного экспорта программа автоматически увеличит на единицу значения всех полей типа "Нумерация" (например, номер исходящего документа).

ТИПЫ ПОЛЕЙ И ИХ ОСОБЕННОСТИ
Текст - Любая произвольная строка.
Число - Только цифры (разрешены точка или запятая для дробных чисел).
Дата - Вводится через три отдельных поля (День, Месяц, Год). Программа автоматически создает скрытые ключи для гибкой вставки в шаблон: день, месяц прописью (например, "января"), месяц числом и год.
Дата со сдвигом - Автоматически вычисляет дату. Например, если "Дата начала" равна 01.01.2024, можно создать поле "Дата окончания", которое будет равно "Дате начала" плюс 14 дней.
Нумерация - Целое число. Автоматически увеличивается на 1 после каждого успешного сохранения документа.

ПРОДВИНУТЫЕ ФУНКЦИИ: РАБОТА С РЕДАКТОРОМ
Если вам нужно поправить сам шаблон (например, изменить шрифт, сдвинуть таблицу или добавить текст), не закрывая программу:
Нажмите кнопку "Открыть в редакторе". Документ откроется в Microsoft Word или LibreOffice.
Внесите изменения в документ и сохраните его (нажав Ctrl+S).
Вернитесь в программу и нажмите "Прочитать из редактора". Программа обновит внутренний текст шаблона, сохранив ваши изменения.
Чтобы вставить заполненные данные в уже открытый файл без создания нового, нажмите "Вставить данные в документ" (эта функция работает в режиме реального времени в MS Word).

ЧАСТЫЕ ВОПРОСЫ И РЕШЕНИЕ ПРОБЛЕМ
Вопрос: Программа не заменяет текст в Word, документ остается с ключами.
Ответ: Убедитесь, что ключи в документе Word в точности совпадают с ключами в программе (включая фигурные скобки). Проверьте, не разбит ли ключ форматированием Word на разные фрагменты (например, скобка выделена жирным, а остальной текст нет). В таком случае удалите ключ в Word и напечатайте его заново обычным текстом.
Вопрос: При массовой вставке часть строк не распознана.
Ответ: Убедитесь, что в копируемом тексте есть явное соответствие: либо точное название поля (например, "Полис ОМС: 123"), либо сам ключ ("{UfCrm1703665989} 123"). Избегайте лишних пробелов и переносов строк внутри одного значения.
Вопрос: Где хранятся мои данные? Пропадут ли они после закрытия?
Ответ: Нет, программа автоматически сохраняет все созданные поля и тексты шаблонов в скрытый файл настроек в вашей пользовательской папке на компьютере. При следующем запуске EXE-файла все ваши поля и шаблоны загрузятся автоматически.
Вопрос: Ошибка "Не удалось подключиться к Microsoft Word" при нажатии "Вставить данные в документ".
Ответ: Эта ошибка возникает, если Word не установлен, не запущен, или блокируется антивирусом. Для простого сохранения файла используйте кнопку "Скачать Word" — она работает всегда и не требует прямого подключения к процессу Word.

ПОЛЕЗНЫЕ СОВЕТЫ
Используйте кнопку "Очистить" в форме поля, чтобы быстро сбросить форму и создать новое поле с нуля.
Снимайте галочку "Видимое" у технических полей, которые нужны только для внутренних расчетов, чтобы они не мешали в общем списке.
Для массовой печати нескольких карт: заполните данные первого пациента, скачайте Word, измените данные на второго пациента и снова скачайте Word. Нумерация документов обновится сама.
